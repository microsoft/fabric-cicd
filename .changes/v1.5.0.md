## [v1.5.0](https://pypi.org/project/fabric-cicd/1.5.0) - November 17, 2026

### 🆕 New Items Support

* Add support for Org App and Org App Audience items by [ayeshurun](https://github.com/ayeshurun) ([#1026](https://github.com/microsoft/fabric-cicd/issues/1026))

### ✨ New Functionality

* Add the `$sqlendpointfqdn` dynamic replacement variable for resolving a SQL Database endpoint FQDN without the server port by [shirasassoon](https://github.com/shirasassoon) ([#1140](https://github.com/microsoft/fabric-cicd/issues/1140))
* Add the `enable_strict_semantic_model_binding` feature flag to fail the deployment on semantic model binding errors by [arhx91](https://github.com/arhx91) ([#1157](https://github.com/microsoft/fabric-cicd/issues/1157))
* Add opt-in Warehouse SQL project deployment while preserving shell-only publishing by default by [shirasassoon](https://github.com/shirasassoon) ([#961](https://github.com/microsoft/fabric-cicd/issues/961))
* Add the `EXTRA_HEADERS` constant to send custom HTTP headers on every Fabric API request by [yaronpri](https://github.com/yaronpri) ([#1186](https://github.com/microsoft/fabric-cicd/issues/1186))

### 🔧 Bug Fix
